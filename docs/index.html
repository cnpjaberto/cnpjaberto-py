cnpjaberto

A Python SDK and Model Context Protocol server for cnpjaberto.com.br — the open registry of every Brazilian company (CNPJ). Look up companies, partnership graphs, addresses, and national statistics from Claude Desktop, Cursor, or any Python script.

View on GitHub Set up MCP → SDK quickstart

Use it from Claude Desktop in 60 seconds

1

Install the package

pip install cnpjaberto[mcp]
2

Drop this in your Claude Desktop config

~/Library/Application Support/Claude/claude_desktop_config.json (macOS) · %APPDATA%\Claude\claude_desktop_config.json (Windows) 

{
  "mcpServers": {
    "cnpjaberto": {
      "command": "cnpjaberto-mcp",
      "env": {
        "CNPJABERTO_API_KEY": "your_key_here"
      }
    }
  }
}

Get a free key at cnpjaberto.com.br/planos. Anonymous usage works too, with public rate limits.

3

Restart Claude and ask anything

"Look up CNPJ 18.236.120/0001-58 and tell me when it was founded and what its main CNAE is."
"How many Brazilian companies opened in 2024 vs 2023? Which states grew the most?"
"Find every active company where 'Maria Silva' appears as a partner — group them by state."
"What other companies share the same registered address as Magazine Luiza's HQ?"

Available tools

ToolWhat it does
lookup_cnpjFull company record: legal name, CNAE, address, partners, capital, branches
list_filiaisBranches of a parent company (paginated, optional UF filter)
search_companiesSearch by name, fantasy name, or CNPJ digits
companies_by_ownerCompanies where a person appears as partner; CPF disambiguates homonyms
companies_at_same_addressOther companies registered at a specific address
companies_by_contactCompanies sharing the same email or phone
cnae_statsAggregate stats for an economic activity code (count, top UFs, mortality)
panorama_overviewNational stats: top UFs, top CNAEs, capital ranges, age buckets, 10y history
panorama_yearYearly snapshot: openings/closings, monthly series, MEI share

Use the SDK directly

from cnpjaberto import Client

with Client() as cnpj:                           # reads CNPJABERTO_API_KEY from env
    nubank = cnpj.lookup("18.236.120/0001-58")
    matriz = nubank["estabelecimentos"][0]
    print(nubank["razao_social"], "—", matriz["situacao_cadastral"])

    snap = cnpj.panorama_year(2024)
    print(f"{snap['abertas']:,} opened, {snap['fechadas']:,} closed in 2024")

Data source

All data comes from the Brazilian Federal Revenue (Receita Federal) public CNPJ dump, refreshed monthly. cnpjaberto.com.br ingests, indexes, and serves it with sub-second lookups, plus value-added joins (partnership graphs, shared addresses, CNAE aggregates) over ~70M establishments and ~67M companies.
